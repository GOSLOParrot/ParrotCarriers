## 2026-04-27 角色设定、UI/UX 风格与协作模式构想

**核心理念**：复杂的管理功能（如 Graphiti 图谱管理）归入 Web 控制台，移动端 App 保持轻量化、趣味性的互动（如批改作业、处理 2D 纸条）。

**角色设定与协作方式**：
- **默认主题（大小姐宅邸）**：GOSLO 是大小姐（核心日常互动对象），Nanobot 是女仆（后台干活，递交纸条报告）。
- **海盗主题（P3 构想）**：User 是船长，GOSLO 是大副（可戴经典眼罩 skin），Nanobot 是水手。
  - **视觉滤镜**：摄像头视角即 User 视角，可加脏兮兮的镜片滤镜，或半边模糊黑色的遮挡（模拟船长戴单眼罩）。
  - **互动道具**：长按屏幕某处可拖动出一个 2D 像素风的望远镜来启动特定功能。

**UI/UX 风格（2D 像素与 3D/AR 现实的结合）**：
- **HUD 设计**：采用 2D 像素风格（如像素风的羊皮纸），用于批改 Google 行程、接收 Nanobot 的像素风纸条报告。
- **设计挑战与学习方向**：
  - **字体可读性**：在像素风 UI（羊皮纸）上显示大量现代文本（如日程）时，如何平衡复古感与可读性？
  - **互动表现**：后台 AI（水手/女仆）递交报告时，UI 如何表现“递交纸条”的动作？（例如：从屏幕底部滑出一张 2D 像素纸条，带音效和轻微摇晃动画，或者伸出一个猫爪子）。
  - **参考竞品**：优秀的 2D 像素独立游戏（如《Papers, Please》或类似森林管理员批改报告的游戏），学习其菜单布局、功能入口和互动玩法设计。

**设计优先级**：
先完成“大小姐宅邸”的日常优秀布局和功能入口设计（主菜单放哪、玩法入口怎么进），再具体优化动画和像素效果。主题切换（海盗风）相当于换肤，但基础的“2D UI + 3D/AR 互动”的底层逻辑是共通的。
