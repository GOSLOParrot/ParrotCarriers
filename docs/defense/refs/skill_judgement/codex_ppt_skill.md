# codex-ppt Skill 判断记录

- 说明：需要重启 Codex 后，新的 skill 才会出现在正式可触发 skill 列表里。

## 适用范围

- 适合把大纲、论文内容、报告内容转换成视觉统一的 PPT。
- 适合生成“整页图片式”的幻灯片，再组装成 `.pptx`。
- 适合当前答辩后期制作视觉统一的 PPT 稿。

## 不适合范围

- 不适合需要每个文本框、图形、表格都可单独编辑的传统 PowerPoint 工作流。
- 不适合在大纲和风格还没确认前直接生成整套幻灯片。

## 对本答辩包的使用方式

- 先在 `drafts/01_outline.md` 完成演讲大纲。
- 再在 `drafts/03_ppt_script.md` 提炼 PPT 页面内容。
- 之后把待确认的 PPT 大纲放到 `ppt_skill_workspace/outline_review/`。
- 风格确认材料放到 `ppt_skill_workspace/style_review/`。
- 样张和反馈放到 `ppt_skill_workspace/sample_review/`。
- 最终产物放到 `ppt_skill_workspace/final_export/`。
