# 01 Input Sources Assets

这个文件夹专门放大纲 `1:30-2:30 场景 Agent 需要哪些输入` 这一分钟使用的图片。

## 推荐结构

| 文件夹 | 放什么 |
| --- | --- |
| `livekit/` | LiveKit 官方 GitHub 截图、Room / Participant / Track 结构图、Data / RPC 文档截图。 |
| `google_calendar/` | Google Calendar 官方界面图、周视图、事件详情、任务和提醒相关图。 |
| `obsidian/` | Obsidian 官方界面图、Daily notes、笔记链接、Graph / Canvas 等直观图。 |
| `nanobot/` | HKUDS/nanobot 官方 GitHub 仓库截图、WebUI / README 截图。 |
| `sva_cv/` | Vision Agents / SVA Processor 相关官方截图，或我们自绘的“视频流 -> Processor -> LLM/DSG”简图。 |
| `project_demo/` | 我们自己的 Obsidian 日记、Demo 截图、后台状态截图。注意隐私打码。 |

## 命名建议

- `livekit_repo_overview.png`
- `livekit_room_track_model.png`
- `google_calendar_week_event.png`
- `obsidian_daily_note_graph.png`
- `nanobot_repo_overview.png`
- `sva_processor_pipeline.png`
- `project_obsidian_diary_blurred.png`

每张图片的来源、用途和版权备注写到 `sources.md`。不要只留下图片文件，否则后续做 PPT 时很难追溯。
