- `01_input_sources/`：放 `1:30-2:30 场景 Agent 需要哪些输入` 这一段的官方截图、仓库截图、产品界面图和简化示意图。

- 后续如果进入 PPT 制作阶段，再按页码新增 `slide_XX_*` 文件夹；当前先按主题收集，避免太早绑定页码。

图片不要散放在 `workbench/` 或 `refs/`。`workbench/` 放判断和调研，`assets/` 放真正可能进 PPT 的视觉素材。
