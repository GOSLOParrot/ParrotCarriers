# PPT 风格方向：白底朴素技术答辩

## 总体判断

当前资料截图大多是黑底网页或 GitHub README，不能直接当 PPT 背景。它们只作为内容素材和视觉证据图使用。

PPT 整体应保持：

- 白色或近白背景。
- 深色文字。
- 正常、清晰、偏高级的字体。
- 大图 + 大字，但版面要素一点、普通一点。
- 不做花背景，不使用大面积渐变、发光、毛玻璃、装饰性元素。

## 版式规则

| 项 | 规则 |
| --- | --- |
| 背景 | 白底或极浅灰底。 |
| 标题 | 深色大字，建议 34-44pt。 |
| 正文 | 深色，建议 22-28pt；每页最多 1-2 句。 |
| 图片 | 作为嵌入截图，放在白底页面中；不要铺满当背景。 |
| 图片处理 | 可加极浅边框或阴影，保持截图边界清楚。 |
| 字体 | 使用正常无衬线字体，优先 Aptos / Microsoft YaHei UI / 思源黑体 / Inter 一类。 |
| 配色 | 黑 / 深灰为主，少量蓝色作强调即可。 |
| 信息量 | 每页只让老师记住一个概念。 |

## 输入源五页建议

| 页 | 推荐版式 |
| --- | --- |
| LiveKit / SVA | 左侧大标题和一句说明，右侧放 LiveKit Docs 截图 + VisionAgents 截图，两个截图并排或上下叠放。 |
| nanobot | 左侧大标题，右侧放 nanobot README 截图；下方一句“后台任务 Agent / Worker 模式参考”。 |
| Google Calendar | 大图居中偏右，左侧或顶部写“日程 / 时间上下文”。 |
| Obsidian | 大图居中偏右，左侧或顶部写“本地知识库 / 日记”。 |
| CV 扩展 | 用 SAM2 / DINOv2 / ConceptGraphs 截图作为三张小图或一张主图；标题写“从画面到对象和关系”。 |

## 禁止事项

- 不把黑底网页截图全屏铺底。
- 不在截图上覆盖大段文字。
- 不用一页塞很多仓库 badge、README 段落或小字表格。
- 不用论文式密集流程图。
- 不让截图里的花哨风格决定整套 PPT 风格。
