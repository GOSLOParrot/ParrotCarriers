# 参考资料库 (references)

> 用途: 存放 Skill Seekers 抓取的原始资料、API 文档、源码解析结果  
> 供 Cursor @doc 引用，丰富上下文

## 建议子目录

| 子目录 | 内容 |
|:-------|:-----|
| `livekit/` | LiveKit agents、python-agents-examples、Unity SDK 的 Skill Seekers 输出 |
| `sva/` | Vision-Agents 解析结果（总线完成后） |
| `openteach/` | OpenTeach 相关（可选） |

## 使用方式

- 用 Skill Seekers 生成后放入对应子目录  
- 在 Cursor 中用 `@docs/references/` 或 `@docs/references/livekit/` 引用
