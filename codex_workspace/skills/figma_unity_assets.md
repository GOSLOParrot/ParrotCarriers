## Rules

- Final art is not required for code progress.
- Placeholder sprites are acceptable and should be easy to replace.
- Prefer stable names over clever names.
- If changing protocol or menu semantics, route through `interface_plan.md` first.

## Completion Signal

Unity has a documented asset folder tree and the first UI scene can render with placeholders or imported Figma sprites.
