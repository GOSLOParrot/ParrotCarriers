# 启动页与启动菜单设计 v0

> 目标：先做一个简单、横屏、像素风、可扩展的启动页。  
> 当前不追求最终美术，重点是布局、模式选择和后续动画留白。

## 画布基准

- 设备参考：iQOO Neo9。
- 设计比例：横屏 20:9。
- Figma 可先用逻辑尺寸 `873 x 393`。
- Unity 后续使用 Canvas Scaler 适配，不把 UI 固定死在物理像素上。

## 第一屏布局

```text
┌──────────────────────────────────────────────────────────────┐
│                                                [ X / EXIT ]   │
```

## 固定元素

| 区域 | 元素 | 设计意图 |
|:--|:--|:--|
| 中央 | `GOSLO Parrot` 标题牌 | 像素木牌或黑底块字，先保留后续换图空间 |
| 标题旁 | 可替换 2D 模型形象位 | 根据 Room Setting 里的 2D model / character 设置替换，先用蓝白鹦鹉占位 |
| 右上 | 小退出按钮 | 参考极简游戏标题页，保持存在但不抢注意力 |
| 左下 | 小基础菜单设置 | 设备、音量、语言、账号、权限、调试入口 |
| 左侧 | `SCENE` | 只显示当前 Scene；点击才进入 Room Setting 菜单 |
| 右侧 | `START` 主按钮 | 进入当前选中的模式 |
| START 旁 | 像素拉杆 / 切换器 | 切换 AR mode 和 2D workspace mode |

## 启动模式

| Mode | 启动内容 | App 体验 |
|:--|:--|:--|
| `AR Scene` | 摄像头 AR、LiveKit 语音房间、GOSLO companion、HUD | 正常主模式 |
| `2D Workspace` | 不开 AR，进入像素宅邸 / 2D 管理工作区 | 管理、批改、整理、报告、任务操作 |
| `Room Only` | 可选后续模式，只进语音/文字房间，不开完整 AR | 低负载连接测试或后台会话 |

## Room Setting 内容

启动页上默认不展开这些字段，只在点击 `Room Setting` 后进入菜单。

| 字段 | 含义 |
|:--|:--|
| `2D model` | 启动页标题旁的可替换像素形象，例如 GOSLO Parrot |
| `Model` | 当前后端模型或模型组 |
| `Scene` | AR scene / 2D scene / 工作区场景 |
| `Room` | 新房间、加入已有房间、测试房间 |
| `Pattern` | 菜单 preset / 行为模式 / 启动模板 |
| `Persona` | 之后可接 PersonaLoader |
| `Maid Team` | 后台 AgentTeam / Maid Team 预设；V1 先固定 `CatMaid Team` |

## 启动动画留白

- 启动页不直接放进度条。
- 进度条 / IPoAC 风格动画拆成点击 START 后的单独转场页。
- 转场页居中显示低保真像素动画：
- 可以播放低保真像素动画：
  - 飞行动物携带 `1TB` 微型 SD 卡包。
  - 进度条长期停在 0%。
  - 文案轮换：`正在计算风阻...`、`正在休息...`。
  - 到达服务器后，进度条从 0% 跳到 100%。
- 这段先做占位，不和启动逻辑强绑定。
