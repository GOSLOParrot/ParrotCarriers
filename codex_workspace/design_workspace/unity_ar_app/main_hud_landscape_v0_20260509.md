# 横屏主页面 HUD / 工具栏设计 v0

> 目标：进入 AR 摄像头画面后，中心尽量干净，功能收在角落，可横向或纵向展开。

## 基本布局

```text
┌──────────────────────────────────────────────────────────────┐
│ [HUD 展开块]                                                  │
│  LiveKit / Brain / Vision / Room                              │
│                                                              │
│                                                              │
│                     Camera / AR View                         │
│                                                              │
│                                                              │
│                                                  [工具抽屉展开] │
│                         camera / photo / bbox / menu / settings│
└──────────────────────────────────────────────────────────────┘
```

## 左上 HUD 展开块

| 状态 | 显示 |
|:--|:--|
| 收起 | 小状态块：连接灯、房间、语音、视觉 |
| 横向展开 | 一排状态 pill：LiveKit、GOSLO、Vision、ECP、BB |
| 竖向展开 | 小面板：连接质量、当前 persona、当前 scene、最近事件 |

## 左下工具栏

更新：横屏时工具栏块放到右下角，形态更像“拉开的抽屉柜子”，不是普通工具条。

| 状态 | 显示 |
|:--|:--|
| 收起 | 右下角工具抽屉块 |
| 横向展开 | 像抽屉向左拉开：相机、拍照、注意力框、菜单画布、2D 工作区、设置 |
| 竖向展开 | 像抽屉向上拉开：工具格 + 每个工具短状态 |

## 交互原则

- 中心摄像头区域不被大面积遮挡。
- 收起态要尽量小，只作为可抓取的 HUD / 工具抽屉把手，不遮挡主要视野。
- 展开方向优先贴边，不挡住角色。
- HUD 固定从左上角展开。
- 工具抽屉固定从右下角展开。
- 两者都允许横向或纵向拉开，由用户按横屏/竖屏手感选择。
- 展开态可以遮挡视野，因为那是用户主动进入操作状态。
- 展开后的栏要比收起态大，并尽量靠边。
- HUD 栏和工具抽屉栏允许重叠，但重叠区域不放工具按钮和 HUD 信息，只作为空白/安全缓冲区域。
- HUD 和工具抽屉需要有明显区分度：HUD 更像暗色状态板 / 连接面板，工具抽屉更像像素木制抽屉柜。
- 所有按钮先做大图标和短标签，长说明放二级面板。
- HUD 状态来自后端/Unity 状态，不在 UI 里硬编码假状态。

## 待对齐后端状态

- LiveKit 连接状态。
- ECP heartbeat / connection health。
- BB active keys。
- PhotoNode 保存状态和图片路径。
- GOSLO aware / intent / plan 状态。
