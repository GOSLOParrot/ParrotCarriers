## 风格关键词

- 像素风，但不是赛博荧光主导。
- 横屏手机布局优先。
- 木牌、纸张、桌面、像素按钮、低分辨率字体可以作为 UI 语言。
- 主角色是鹦鹉，外部模块角色可以变成不同 NPC 或小助手。
- 启动动画可以有轻松幽默的“慢连接 / 延迟 / 最后一瞬间完成”节奏。

## 授权检查

素材入仓前需要记录：

- 来源链接
- 授权类型
- 是否可商用
- 是否可修改
- 是否需要署名
- Unity 使用路径
