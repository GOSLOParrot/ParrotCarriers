## 使用规则

- 如果要改“源事实”，回 `.cursor/memory` 的对应文件；如果只是做草图和 UI idea，请在本设计工作区继续写。
- 后续可以加 `figma_notes/` 或 `sketch_notes/`，但先不要把这里变成第二个 memory 迷宫。
