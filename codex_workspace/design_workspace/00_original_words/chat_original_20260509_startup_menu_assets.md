## 启动页

- 启动页整体希望是像素风格。
- 布局简单，用手机横屏布局。
- 左下角放一个小的基础菜单设置。
- 右上角放一个小的退出。
- 中间简单写 `GOSLO Parrot`。
- 放几个小一点的启动选项。
- 左边一个 `SCENE` 设置的 `Room Setting`，可以调：
  - Model
  - Scene
  - Room
  - 新房间
  - Pattern 预设
- 右边一个 `STAR/START` 按钮。
- `START` 可以选择展开，或者旁边设计一个像素拉杆切换 Mode。
- 启动模式需要区分：
  - 正常 mode：AR Scene、语音对话等。
  - 纯 2D mode：不开启 AR，直接进入 2D 管理工作区。

## 2D 工作区

- 2D 管理工作区参考像素大厅，可以像宅邸主大厅。
- 用户可以去不同区域完成不同任务、工作桌操作、工作批改等。
- 宅邸内有角色可以对话。
- 角色方向：
  - 主角色仍以鹦鹉为核心。
  - 可以有 Gemini App / Gmail 等副驾驶飞行员姐姐。
  - 可以有女仆装橘色猫猫。
  - nanobot 参考原 GitHub 项目形象。
- 2D 工作区域交互可以学习 Papers, Please：
  - 工作桌
  - 盖章
  - 驳回
  - 丢到垃圾桶
  - 文档拖拽和审查

## 启动转场动画

- 启动转场动画先留空间，后面再设计，好改。
- LiveKit 启动动画再找参考。
- 先做简单进度条动画和飞行动物。
- 低保真像素风格，符合 IPoAC。
- 例子：像素飞鸟背着写着 `1TB` 的微型 SD 卡包，从左慢慢飞到右边。
- 进度条底下可以显示：
  - 正在计算风阻...
  - 正在休息...
- 特性：
  - 百分比长期停在 0%。
  - 飞到右侧，把 SD 卡丢进服务器的一瞬间，进度条从 0% 跳到 100%。
  - 中间可以停下来休息，或者遭遇延迟阻碍。
